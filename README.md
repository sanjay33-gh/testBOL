# testBOL

A simple test application to demonstrate basic functionality.

## Prerequisites

- Python 3.x installed on your system

## How to Run the App

1. Clone this repository:
   ```bash
   git clone https://github.com/sanjay33-gh/testBOL.git
   cd testBOL
   ```

2. Run the application:
   ```bash
   python3 app.py
   ```
   
   Or make it executable and run directly:
   ```bash
   chmod +x app.py
   ./app.py
   ```

## What the App Does

The application is a simple Python script that:
- Displays a welcome message
- Shows the current date and time
- Displays the Python version being used
- Confirms successful execution

This is a basic demonstration app perfect for testing and learning purposes.
